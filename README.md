# Student Performance Data Preparation

## Overview

This project focuses on inspecting, cleaning and preparing a student performance dataset for future machine learning applications.

## Dataset

- **Dataset:** Student Performance Factors
- **Source:** [Kaggle – Student Performance Factors](https://www.kaggle.com/datasets/lainguyn123/student-performance-factors)
- **File:** `StudentPerformanceFactors.csv`
- **Domain:** Education

The dataset contains information about students' study habits, attendance, parental involvement, lifestyle factors and examination scores.

## Work Completed

1. Loaded and inspected the dataset.
2. Identified numerical and categorical features.
3. Analysed summary statistics and missing values.
4. Handled missing values using median and mode imputation.
5. Checked duplicate records and category consistency.
6. Performed exploratory data analysis (EDA).
7. Created visualisations to examine the dataset.
8. Applied one-hot encoding to categorical features.
9. Standardised suitable numerical features using StandardScaler.
10. Verified and exported the prepared dataset.

## Files

- `StudentPerformanceFactors.csv` – Original dataset.
- Completed Activity 1 notebook – Data inspection, cleaning and preprocessing.
- `student_performance_prepared.csv` – Final prepared dataset.

## Tools and Libraries

## Conclusion

The dataset was inspected, cleaned and transformed through missing-value handling, duplicate checking, exploratory analysis, categorical encoding and numerical scaling. The final prepared dataset is available as a separate CSV file for future machine learning tasks.
